# 第一版上线验收标准

对应规格第20节全部25项。本表说明如何验收，不发布具体实例的结果。
真实证据与未完成门禁在私有台账分别维护；未执行、失败和待用户操作不能记为通过。

| # | 要求 | 负责阶段 | 验收方法 |
|---|---|---|---|
| 1 | accounts 子域名有效 HTTPS | 5 | 核验真实域名、证书主机名/链/有效期、续期 dry-run 和 timer；结果存私有侧 |
| 2 | HTTP 跳转 HTTPS | 5 | 公网 HTTP 301 到精确 HTTPS 地址，HTTP 不接受凭据 |
| 3 | 无公开注册接口 | 0/1 | 契约与路由无注册 API，仅 CLI 能初始化唯一管理员 |
| 4 | 管理员密码 Argon2id | 1 | 测试 Argon2id 验证及过时哈希升级 |
| 5 | 生产强制 TOTP | 0/1/5 | 生产配置拒绝关闭 TOTP；真实完整认证在私有实例验收 |
| 6 | HttpOnly/Secure/Strict Cookie | 1/5 | 验证 __Host- Cookie 的 Secure/HttpOnly/Strict/Path=/、轮换及撤销 |
| 7 | 所有修改请求 CSRF | 1—4 | 覆盖全部修改入口、预会话和刷新轮换；拒绝无效 CSRF/Origin |
| 8 | Nginx+应用登录限流 | 1/5 | 验证应用退避/锁定和 Nginx 429，伪造转发来源不能绕过 |
| 9 | 数据库/API 内部端口不公开 | 0/5 | 核查实际端口发布、公网不可达和宿主机回环 ready；保留私有证据 |
| 10 | 密码/手机号/备注 AES-GCM | 0/1/2 | 测试版本化 AES-GCM/AAD、nonce、错误密钥和认证失败 |
| 11 | 数据密钥不在 DB/Git/镜像 | 0/1/5 | 检查 Secret 只读白名单、镜像/构建物/日志及各版本密钥离线保管 |
| 12 | 普通列表/详情无密码/密文 | 2 | 检查列表/详情响应白名单，无密码与密文字段 |
| 13 | 显示密码最近重新验证 | 1/2 | 服务端敏感 POST 验证最近重新验证，前端20秒/隐藏/退出清理及晚到响应隔离 |
| 14 | 规范化 Gmail 唯一 | 0/2 | 测试 Gmail 规范化、DB 唯一约束、并发409和软删除保留唯一性 |
| 15 | CRUD/筛选/归档/软删除/恢复 | 2/3 | 测试 CRUD、版本冲突、组合查询/分页、批量事务和软删除恢复 |
| 16 | 外部/关联辅助邮箱 | 0/2 | 测试外部文本/关联切换、XOR/自身/同邮箱和已删除关联语义 |
| 17 | 状态/用途/标签/时间筛选 | 3 | 验证组合条件、浏览器时区到UTC半开边界、稳定排序与URL恢复 |
| 18 | CSV 预览和提交 | 4 | 测试格式/大小/映射/重复策略、两阶段绑定、事务和错误脱敏 |
| 19 | 默认导出不含敏感字段 | 4 | 核对精确字段白名单、全匹配范围、CSV转义/公式处理及审计 |
| 20 | 自动备份及恢复演练 | 4/5 | 分别验收手工备份、正式自然调度、异地取回和独立PG18全量恢复/抽样解密 |
| 21 | 日志无敏感明文 | 0—5 | 检查请求/错误/审计/访问日志及构建物不含凭据或业务原文 |
| 22 | Alembic 空库完整执行 | 0—5 | 独立 PG18 空库执行迁移，验证旧数据保持、角色权限和迁移漂移 |
| 23 | 后端/前端/关键 E2E 通过 | 0—5 | 按改动运行后端/前端/关键E2E；响应桩、真实联调、CI与跨浏览器分别记录 |
| 24 | 完整部署/升级/备份/恢复说明 | 每阶段 | 交付通用手册和私有实例配置、精确回退、恢复演练及离线保管责任 |
| 25 | 生产无 debug/公开 Swagger | 0/5 | 核查实际配置、公开docs/OpenAPI关闭、错误无堆栈、无通配CORS |

## 不能合并的证据

代码测试、PG18/Linux 容器、服务启用、手工备份、首次正式自然调度、异地取回、隔离恢复和离线保管分别留证。
不把临时验收的改期触发、PG17 恢复、API 响应桩或配置存在当作正式生产通过。
原始记录、实际发布/镜像、证书时间、端口/路由与恢复拓扑只保存在私有侧。
操作入口见 [验收指南](validation.md)，生产变更顺序见 [上线清单](phase5-launch-checklist.md)。
