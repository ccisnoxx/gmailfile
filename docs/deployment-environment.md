# 部署前只读检查

按具体实例填写检查结果，并将原始输出和真实值保存在私有配置库。
本页只列检查项，不包含服务器清单或当前容量结论。

## 先核对管理入口与保护对象

- 核对当前 SSH 配置解析后的目标、端口、身份与已信任主机公钥。
- 管理入口不可达时停止受影响操作；备用路径须由运营者确认，不关闭主机密钥检查。
- 记录本次允许修改的对象，以及不能触碰的服务、数据库、卷、网络、备份和共享入口。
- 不为检查启动容器、安装软件、拉取镜像、重启服务或清理资源。

## 检查部署条件

| 检查项 | 应记录的证据 |
|---|---|
| 系统与架构 | Linux 发行版、CPU 架构和所需工具版本 |
| 容量 | 可用内存/磁盘、负载、swap 与持续换页情况 |
| 端口 | 现有监听、API 回环端口冲突、PG 不公开 |
| 网络 | 私网连通、路由来源、Docker 网段冲突、真实代理 socket peer |
| 入口 | DNS A/AAAA、TLS 终止点、HTTP-01 可达性、代理头信任边界 |
| 存储 | 已有目录/卷归属、文件权限、Secret 与离线恢复材料保管 |
| 恢复 | 独立健康核查通道、旧发布/配置和已验证备份 |

容量和路由是时点事实，执行变更前重新核对。
前置条件满足后按 [部署手册](production-deployment.md) 和 [上线清单](phase5-launch-checklist.md) 操作。
